## Setup
### Backend (Python)
#### python modules:
flask

argon2-cffi

firebase_admin

flask_cors

#### setup venv
Create a venv (Virtual environement)
```
cd backend
mkdir venv
python -m venv venv
```

Install Modules```pip install modulename```

Befor running Python programs connect to venv. ```source venv/bin/acitvate```

Then run using ```python main.py```
